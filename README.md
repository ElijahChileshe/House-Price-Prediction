# 🏠 House Price Prediction Model

This project is a simple machine learning implementation for predicting house prices based on features such as location, number of bedrooms, bathrooms and square footage.

## 📊 Project Overview

The goal is to train a regression model that can predict the price of a house using historical data. The model uses a dataset from Horizon Properties and is built with Python using popular ML libraries.

## 🔧 Tools and Technologies

- Python 3.x
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook or any Python IDE

## 🧠 Model Description

The model uses a supervised machine learning approach Random Forest trained on features such as:

- Location
- Number of bedrooms
- Square footage
